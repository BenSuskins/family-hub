# Cosier Warm Sage

The user selects Warm Sage and asks for a more cosy family feel. This refinement keeps the agreed content and interactions.

- Warm oat canvas and cream content surfaces.
- Sage actions with muted clay details.
- Rounded system headings with the standard system body font.
- Soft icon backgrounds on the overview rows.
- Warm charcoal and cream text in the dark sample.

Keep the Food and Household overview screens. Keep meals above chores, inline rename, and the five-second purchase Undo. Keep the existing Calendar design. Show no arrival-margin text.

[Compare the two versions](../cosy-sage.html). [Read the static checks](checks.json).

The six new images cover five key screens and dark Today. The checks measure phone widths, selected text contrast, image load, and gallery layout. These are static mockups, not a native implementation or a full accessibility assessment.
