# Visual directions

Three directions cover Today, Food overview, Household overview, Shopping list, and Recipe detail. Each direction includes a dark Today sample. The current proposals remain the reference.

| Direction | Palette | Surface and shape |
|---|---|---|
| A · Quiet neutral | White, charcoal, restrained blue links | Flatter groups, 16-point corners, dark main buttons |
| B · Warm sage | Warm stone, soft white, forest green | Rounded groups, a tinted departure card, softer contrast between surfaces |
| C · Cool indigo | Cool grey, white, indigo | Fine borders, 20-point group corners, clear surface boundaries |

These are visual choices, not new navigation proposals. Keep the selected overview screens, inline rename, purchase Undo, and existing Calendar. Keep the system typeface. Do not apply a direction to the app before the user selects it.

The palette search identifies teal as a productivity direction. The sage version uses a darker green to keep white button text legible. The broad design-system query returns AI and marketing patterns; those patterns do not fit this app and are excluded. The neutral and indigo treatments are authored alternatives. The SwiftUI colour search returns no verified theme-specific result; these samples use explicit semantic tokens and measured contrast as a fallback.

The [Apple Design skill](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md) guides restraint, material hierarchy, typography, and native controls. [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) guides palette exploration and contrast checks. Use native adaptive colours and system controls during implementation. The CSS colours approximate the intended appearance.

[View the comparison gallery](../style-options.html). [Read the static checks](checks.json).

The checks cover both phone widths, selected text colours against their composed surfaces, image load, gallery width, and comparison filters. They do not prove native Dynamic Type, VoiceOver, full dark-mode coverage, or motion. Dark Today gives an initial appearance sample for each direction.
