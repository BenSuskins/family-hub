# Calendar rebuild

These screenshots show fixed demo data on an iPhone 17 Pro simulator with iOS 26.5.
They show the month in Details mode and the day timeline with overlapping events.

Run `CalendarUITests` with Xcode to capture the views. The tests use the
`-calendar-fixtures` launch argument. This argument changes demo data only.

The first visit opens Details mode. Pinch the month to change its density.
Tap a date to open the day timeline. Use the view menu for other views.
